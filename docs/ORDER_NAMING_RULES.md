# Order Naming Rules

## Purpose

Every order should have a clear, stable, human-readable project name that describes the real customer project.

The project name is not the primary key. The permanent `Project ID` is the primary key. But the project name should still be useful for humans reviewing the spreadsheet.

## Never Use Communication Labels

Do not use email subjects or workflow labels as project names.

Never save project names like:

- Inquiry
- Get a Quote
- Request for Quote
- RFQ
- Quote
- Estimate
- Pricing
- Follow Up
- Production Update
- Permit Question
- Wholesale Channel Letters from Top Channel Letters
- Channel Letter Fabrication Support in Chicago

These phrases describe the conversation, not the project.

## Use Real Project Content

Use the real commissioned content found in the email body, attachments, quoted scope, or confirmed project context.

Preferred sources:

1. End-customer brand or business name.
2. Project location or site name.
3. Product being quoted or produced.
4. Sign company customer plus product/location when the end customer is unknown.

Examples:

| Bad Subject-Derived Name | Correct Project Name |
| --- | --- |
| Estimate daydream | daydream |
| Re: Request for Quote | Backlit Letters With Acrylic Backer |
| Signarama Inquiry for Pricing | Busby Channel Letters |
| Awning quote - Naperville | Naperville Awning |
| RFQ - Pure Barre | Pure Barre Channel Letters |
| Fw: Specs & Logo for BLADE Sign | Blade Sign And Channel Letters |

## Quote-Only Status

If a customer asks for pricing, TCL reviews artwork/source files for pricing, and Charles replies with a price, the status remains `Estimate`.

Do not upgrade the status only because:

- an Illustrator/source file was provided to calculate pricing;
- a mockup was created to support the estimate;
- pricing mentions fabrication, installation, or removal;
- the customer asks a clarification after receiving price;
- the customer says "thanks" or "I'll stay in touch."

Upgrade only after a later email confirms approval, deposit/payment, permit work for an accepted job, production release, or scheduled installation.

## Golden Rule

Project names should describe the real sign job.

Statuses describe progress.

Email subjects describe conversations.
