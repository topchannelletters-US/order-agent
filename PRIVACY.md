# Privacy Policy

Last updated: August 11, 2026

## Overview

Order Agent is an internal business automation tool operated by TCL Signs. It is used to review authorized business email and maintain internal order-tracking records.

## Google user data accessed

Order Agent may access Gmail messages and message metadata from Google accounts that have explicitly authorized the application. This can include sender and recipient addresses, subject lines, message bodies, timestamps, thread identifiers, and attachment metadata when necessary for order processing.

## How data is used

Google user data is used only to:

- Identify customer order conversations.
- Match email threads to existing orders.
- Determine confirmed order status changes.
- Update internal order records and activity notes.
- Produce internal operational reports.

Order Agent does not use Google user data for advertising, profiling, or unrelated purposes.

## Data sharing

Google user data is not sold, rented, or shared with third parties. Access is limited to authorized TCL Signs personnel and service providers required to operate the internal workflow, subject to appropriate access controls.

## Data storage and security

OAuth credentials are stored as encrypted repository secrets and are not committed to source control. Processed order information may be stored in access-controlled business systems and repositories. Reasonable administrative and technical safeguards are used to prevent unauthorized access, disclosure, or alteration.

## Data retention and deletion

Information is retained only as long as reasonably necessary for internal business operations and recordkeeping. Authorized users may revoke the application's Google Account access at any time through their Google Account security settings.

Requests to access or delete data associated with this application may be submitted using the contact information below.

## Limited use disclosure

Order Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
